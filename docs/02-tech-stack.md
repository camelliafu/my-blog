# 技术栈说明

## 前端

- Next.js
- TypeScript
- Tailwind CSS
- App Router

选择原因：

- 适合博客类网站
- 支持 SEO
- 支持服务端渲染
- 生态成熟
- 后续方便扩展后台管理页面

## 后端

- NestJS
- TypeScript

选择原因：

- 结构清晰
- 工程化程度高
- 适合长期项目
- 后续方便接入数据库、登录、权限、缓存等功能

## 数据库

计划使用 MySQL。

## ORM

计划使用 Prisma。

## 部署

计划使用：

- Docker
- Nginx
- Linux Server
